Bienvenido a la página oficial de reef-pi, un controlador para acuario marino basado en Raspberry Pi

reef-pi es un controlador modular, asequible y extensible de tipo DIY que puede automatizar tareas diarias de mantenimiento de arrecifes como auto relleno, control de temperatura, ciclo de luz de amanecer a atardecer, dosificación automática, monitoreo de pH y más.

El proyecto reef-pi proporciona software de código abierto, lista de piezas y documentación para construir el controlador físico. Los usuarios construyen el controlador físico utilizando estas guías y software.

A continuación se muestra una lista de tutoriales introductorios, paso a paso, sobre cómo construir el controlador reef-pi. Recomendamos comenzar con la primera guía que cubre la instalación y configuración del software y luego usar las guías específicas de características individuales para tu construcción.
